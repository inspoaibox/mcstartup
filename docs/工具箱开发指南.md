## 🚀 快速开始

### 工具类型

McStartUP 支持三种类型的工具：

| 类型     | 说明               | 示例             |
| -------- | ------------------ | ---------------- |
| `window` | 独立窗口工具       | 计算器、待办事项 |
| `inline` | 内嵌工具（未实现） | -                |
| `link`   | 外部链接           | 在线工具         |

### 文件结构

```
src/
├── tools/
│   ├── registry.ts          # 工具注册表
│   ├── YourTool.tsx         # 工具组件
│   └── useToolTheme.ts      # 主题钩子（必须使用）
├── stores/
│   └── toolDataStore.ts     # 统一数据存储
├── App.tsx                  # 路由配置
src-tauri/src/
├── commands.rs              # 后端命令
└── main.rs                  # 命令注册
```

## 🔧 添加普通工具

### 步骤 1：注册工具

在 `src/tools/registry.ts` 中添加工具定义：

```typescript
const tools: ToolDefinition[] = [
  {
    id: 'your-tool', // 唯一标识（小写，用连字符）
    name: '你的工具', // 显示名称
    description: '工具的简短描述', // 描述（显示在卡片上）
    keywords: ['关键词1', '关键词2', 'keyword'], // 搜索关键词
    categoryId: 'efficiency', // 分类：efficiency/text/network/dev/other
    icon: '🔧', // Emoji 图标
    type: 'window', // 类型：window/inline/link
    windowLabel: 'tool-your-tool', // 窗口标签（必须以 tool- 开头）
    windowWidth: 800, // 窗口宽度
    windowHeight: 600, // 窗口高度
  },
  // ... 其他工具
];
```

### 步骤 2：配置窗口

在 `src-tauri/src/commands.rs` 的 `show_tool_window` 函数中添加窗口配置：

```rust
let (width, height, resizable, always_on_top) = match label_clone.as_str() {
    "tool-your-tool" => (800.0f64, 600.0f64, true, false),
    // ... 其他工具

let title = match label_clone.as_str() {
    "tool-your-tool" => "你的工具",
    // ... 其他工具

```

### 步骤 3：创建工具组件

创建 `src/tools/YourTool.tsx`：

```typescript
import { useToolTheme } from './useToolTheme';
import { appWindow } from '@tauri-apps/api/window';
import { X } from 'lucide-react';

          你的工具
        </span>
        <button
          onClick={() => appWindow.hide()}
          className="p-1.5 rounded-lg text-gray-400 hover:text-gray-600 dark:hover:text-gray-300 hover:bg-gray-100 dark:hover:bg-gray-800 transition-colors"
        >
          <X size={16} />
        </button>
      </div>

      {/* 工具内容 */}
      <div className="flex-1 p-4 overflow-y-auto">
        {/* 你的工具界面 */}
      </div>
    </div>
  );
}
```

### 步骤 4：添加路由

在 `src/App.tsx` 中添加路由：

```typescript
import YourTool from './tools/YourTool';

// 在 App 函数中添加：
if (windowLabel === 'tool-your-tool') {
  return <YourTool />;
}
```

现在你的工具会自动出现在工具箱中，点击即可打开。

## 💾 添加带数据的工具

对于需要保存用户数据的工具（如待办事项、笔记等），使用统一的数据存储系统。

### 数据存储架构

```
用户数据存储位置：
%APPDATA%/McStartUP/tool_data.json

数据结构：
{
  "todo": {
    "tasks": [...],
    "lastModified": "2026-04-18T10:00:00Z"
  },
  "notes": {
    "items": [...],
    "lastModified": "2026-04-18T10:00:00Z"
  }
  // ... 其他工具数据
}
```

### 步骤 1：定义数据类型

在 `src/stores/toolDataStore.ts` 中添加你的数据类型：

```typescript
// 1. 定义你的数据类型
export interface YourToolItem {
  id: string;
  title: string;
  content: string;
  createdAt: string;
  // ... 其他字段
}

// 2. 添加到 ToolData 接口
export interface ToolData {
  todo: {
    tasks: TodoTask[];
    lastModified: string;
  };
  yourTool: {
    // 添加你的工具数据
    items: YourToolItem[];
    lastModified: string;
  };
}

// 3. 更新默认数据
const defaultToolData: ToolData = {
  todo: {
    tasks: [],
    lastModified: new Date().toISOString(),
  },
  yourTool: {
    // 添加默认数据
    items: [],
    lastModified: new Date().toISOString(),
  },
};
```

### 步骤 2：添加数据操作方法

在 `src/stores/toolDataStore.ts` 的 `ToolDataState` 接口中添加方法：

```typescript
interface ToolDataState {
  // ... 现有字段

  // 添加你的工具数据操作方法
  updateYourToolItems: (items: YourToolItem[]) => void;
}

export const useToolDataStore = create<ToolDataState>((set, get) => ({
  // ... 现有方法

  // 实现你的数据操作方法
  updateYourToolItems: (items: YourToolItem[]) => {
    set((state) => ({
      data: {
        ...state.data,
        yourTool: {
          items,
          lastModified: new Date().toISOString(),
        },
      },
    }));
    // 自动保存到文件
    get().saveData();
  },
}));
```

### 步骤 3：在组件中使用数据存储

```typescript
import { useEffect, useState } from 'react';
import { useToolDataStore, type YourToolItem } from '../stores/toolDataStore';

export default function YourTool() {
  const ready = useToolTheme();
  const { data, loaded, loadData, updateYourToolItems } = useToolDataStore();
  const [items, setItems] = useState<YourToolItem[]>([]);

  // 1. 加载数据
  useEffect(() => {
    if (!loaded) {
      loadData();
    }
  }, [loaded, loadData]);

  // 2. 同步数据到本地状态
  useEffect(() => {
    if (loaded) {
      setItems(data.yourTool.items);
    }
  }, [loaded, data.yourTool.items]);

  // 3. 保存数据（当 items 变化时自动保存）
  useEffect(() => {
    if (loaded && items.length >= 0) {
      updateYourToolItems(items);
    }
  }, [items]);

  // 4. 操作数据
  const addItem = (title: string, content: string) => {
    const newItem: YourToolItem = {
      id: Date.now().toString(),
      title,
      content,
      createdAt: new Date().toISOString(),
    };
    setItems([...items, newItem]);
  };

  const updateItem = (id: string, updates: Partial<YourToolItem>) => {
    setItems(items.map((item) => (item.id === id ? { ...item, ...updates } : item)));
  };

  const deleteItem = (id: string) => {
    setItems(items.filter((item) => item.id !== id));
  };

  if (!ready) return null;

  return (
    <div className="flex flex-col h-screen bg-white dark:bg-gray-900 rounded-2xl overflow-hidden">
      {/* 你的工具界面 */}
    </div>
  );
}
```


### 前端存储流程

```
1. 组件挂载
   ↓
2. 调用 loadData() → invoke('load_tool_data')
   ↓
3. 读取 JSON 文件 → 解析数据
   ↓
4. 更新 Zustand store
   ↓
5. 组件通过 useEffect 同步数据
   ↓
6. 用户操作修改数据
   ↓
7. 调用 updateXXX() → 自动触发 saveData()
   ↓
8. invoke('save_tool_data') → 写入 JSON 文件
```

## 📝 完整示例：待办事项工具

### 1. 数据类型定义

```typescript
// src/stores/toolDataStore.ts
export interface TodoTask {
  id: string;
  title: string;
  completed: boolean;
  quadrant: 'Q1' | 'Q2' | 'Q3' | 'Q4';
  deadline?: string;
  notes?: string;
  createdAt: string;
}
```

### 2. 工具注册

```typescript
// src/tools/registry.ts
{
  id: 'todo',
  name: '待办事项',
  description: '四象限任务管理（艾森豪威尔矩阵）',
  keywords: ['待办', '任务', 'todo', '四象限'],
  categoryId: 'efficiency',
  icon: '✅',
  type: 'window',
  windowLabel: 'tool-todo',
  windowWidth: 1000,
  windowHeight: 700,
}
```

### 3. 组件实现

```typescript
// src/tools/TodoTool.tsx
export default function TodoTool() {
  const ready = useToolTheme();
  const { data, loaded, loadData, updateTodoTasks } = useToolDataStore();
  const [tasks, setTasks] = useState<TodoTask[]>([]);

  // 加载数据
  useEffect(() => {
    if (!loaded) loadData();
  }, [loaded, loadData]);

  // 同步数据
  useEffect(() => {
    if (loaded) setTasks(data.todo.tasks);
  }, [loaded, data.todo.tasks]);

  // 自动保存
  useEffect(() => {
    if (loaded && tasks.length >= 0) {
      updateTodoTasks(tasks);
    }
  }, [tasks]);

  // CRUD 操作
  const addTask = (title: string) => {
    setTasks([...tasks, {
      id: Date.now().toString(),
      title,
      completed: false,
      quadrant: 'Q1',
      createdAt: new Date().toISOString()
    }]);
  };

  const updateTask = (id: string, updates: Partial<TodoTask>) => {
    setTasks(tasks.map(t => t.id === id ? { ...t, ...updates } : t));
  };

  const deleteTask = (id: string) => {
    setTasks(tasks.filter(t => t.id !== id));
  };

  if (!ready) return null;

  return (
    <div className="flex flex-col h-screen bg-white dark:bg-gray-900 rounded-2xl overflow-hidden">
      {/* 工具界面 */}
    </div>
  );
}
```

## ✅ 最佳实践

### 1. 必须使用 `useToolTheme`

```typescript
const ready = useToolTheme();
if (!ready) return null;
```

这确保主题在渲染前加载完成，避免闪烁。

### 2. 标题栏必须可拖动

```typescript
<div data-tauri-drag-region>
  <span data-tauri-drag-region>标题</span>
</div>
```

所有标题栏元素都需要 `data-tauri-drag-region` 属性。

### 3. 使用统一的样式类

```typescript
// 背景
className = 'bg-white dark:bg-gray-900';

// 边框
className = 'border border-gray-200 dark:border-gray-800';

// 文字
className = 'text-gray-800 dark:text-gray-200';

// 按钮
className = 'hover:bg-gray-100 dark:hover:bg-gray-800';
```

### 4. 数据保存时机

- ✅ 使用 `useEffect` 监听数据变化自动保存
- ✅ 保存操作是异步的，不会阻塞 UI
- ❌ 不要在每次操作后手动调用 `saveData()`

### 5. 错误处理

```typescript
useEffect(() => {
  loadData().catch((error) => {
    console.error('加载数据失败:', error);
    // 使用默认数据
  });
}, []);
```

### 6. 性能优化

```typescript
// 使用 React.memo 避免不必要的重渲染
const TaskItem = React.memo(({ task, onUpdate, onDelete }) => {
  // ...
});

// 使用 useCallback 缓存回调函数
const handleUpdate = useCallback((id: string, updates: Partial<Task>) => {
  updateTask(id, updates);
}, []);
```

## 💡 常见问题

### Q: 为什么我的工具没有出现在工具箱中？

A: 检查 `registry.ts` 中的 `id` 是否唯一，`windowLabel` 是否以 `tool-` 开头。

### Q: 为什么窗口无法拖动？

A: 确保标题栏元素都有 `data-tauri-drag-region` 属性。

### Q: 数据没有保存怎么办？

A: 检查：

1. 是否调用了 `loadData()`
2. `useEffect` 依赖是否正确
3. 控制台是否有错误信息

### Q: 如何支持数据导入导出？

A: 使用 `exportData()` 和 `importData()` 方法，未来会添加 UI 界面。
